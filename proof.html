Don't take my word for it

Run the checks yourself · made-up invoices, real rules, real code

The portfolio says the booking pipeline catches wrong files, misread tax and double bookings. This page lets you try to break it.

Below are the gates a purchase bill passes before it goes into NetSuite, and the oldest-first rule the prepayment bot follows. They run in your browser on invoices I made up. Change any number and press the button... the rules either catch it or they don't.

What this is, honestly. The rules here are a JavaScript copy of the Python that runs in production. The Python itself is public in chandanpanda615-lab/automation, client names and numbers replaced. That code is a 27 September snapshot, from before the pipeline went to eight brands. The prepayment bot and the newer multi-brand code aren't public yet.

What each gate is for, and where it lives in the code.

GateThe ruleWhy it exists
LedgerStrip a year suffix (-26, /2026, _2026) and leading zeros, then look the number up in the booked ledger.The upload adds suffixes NetSuite never stores. A leading zero booked one bill twice on 8 October.
Right fileThe invoice number in the e-invoice QR must be this row's number. qr_status()Hubs upload the wrong PDF. One hub, one day: 15 of 26.
Nothing read / 40%All taxable zero, or any 40% line, goes to a person.Free goods and samples look like zero bills. 40% is rare enough that a person should see every one.
Tax checksum5% × base + 18% × base must equal the printed tax, within ₹1. reconcile()Catches a misread digit or a decimal in the wrong place.
Invoice amountTaxable + printed tax must equal the printed invoice amount, within ₹1. amt_gap()A read that doubles every line still passes the checksum. It doesn't pass this.
QR totalTaxable + computed tax must equal the QR total, within ₹1. qr_gap()The QR is read by code, not the AI, so a misread can't agree with it by accident. Swapped slabs that add up perfectly get caught here.
ExportOne failing row blocks the whole import file.Half a batch in NetSuite is worse than none. Fix the row or accept it by name.

Tax type is derived, never typed: same state means CGST + SGST, different state means IGST. TDS under 194Q is 0.1% of taxable, and the bill amount is taxable + GST − TDS.
